## 第一，程序入口

Java 必须定义类，还要写 main 方法才能运行程序；Python 不用类、也不用 main 方法，直接写代码就能运行。

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

```python
print("Hello Python")
```

## 第二，基本类型

Java 有 int、double、boolean、String，还要区分基本类型和包装类。Python 一切皆对象，不用区分，类型提示只是注解，运行时不强制。null 对应 Python 的 None，True 和 False 首字母必须大写。

```java
int num = 42;
double price = 19.99;
boolean flag = true;
String text = "hello";
```

```python
num: int = 42
price: float = 19.99
flag: bool = True
text: str = "hello"
nothing = None
```

## 第三，字符串处理

Java 用加号拼接字符串，Python 标配 f-string，直接在字符串里写变量和表达式，非常方便。多行文本 Python 用三个引号就能写，不用像 Java 那样等高版本才支持文本块。

```java
String name = "张三";
int age = 30;
String str = "我叫" + name + "，明年" + (age + 1) + "岁";
```

```python
name = "张三"
age = 30
str = f"我叫{name}，明年{age + 1}岁"

sql = """
SELECT * FROM users WHERE age > 18
"""
```

## 第四，条件与循环

Java 用大括号包裹代码，Python 靠缩进区分代码块，else if 简写为 elif。Java 的普通 for 循环写法固定，Python 直接用 for 迭代列表，需要索引就用 enumerate，range 可以快速生成数字序列，用起来更简单。

```java
int score = 85;
String level;
if (score >= 90) {
    level = "A";
} else if (score >= 80) {
    level = "B";
} else {
    level = "C";
}

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

```python
score = 85
if score >= 90:
    level = "A"
elif score >= 80:
    level = "B"
else:
    level = "C"

for i in range(5):
    print(i)
```

## 第五，集合操作

Java 的 List 对应 Python 的 list，用中括号。Map 对应 Python 的 dict，用大括号。Set 对应 Python 的 set。Python 支持负索引，取最后一个元素非常方便，get 方法相当于 Java 的 getOrDefault，语法更简洁。

```java
List<String> names = new ArrayList<>();
names.add("Alice");

Map<String, Object> user = new HashMap<>();
user.put("name", "张三");

Set<String> skills = new HashSet<>();
skills.add("Java");
```

```python
names = ["Alice", "Bob"]
names.append("David")

user = {"name": "张三", "age": 30}
print(user.get("email", "未知"))

skills = {"Java", "Python"}
skills.add("K8s")
```

## 第六，推导式

这是 Java Stream 的 Python 简化版，一行就能完成过滤、转换、收集。列表推导式、字典推导式，代码量比 Java 少一大半，可读性更高，写数据处理特别高效。

```java
List<Map<String, Object>> users = new ArrayList<>();
List<String> adultNames = users.stream()
    .filter(u -> (int)u.get("age") > 18)
    .map(u -> (String)u.get("name"))
    .collect(Collectors.toList());
```

```python
users = [{"name": "张三", "age": 20}, {"name": "李四", "age": 15}]
adult_names = [u["name"] for u in users if u["age"] > 18]
name_age = {u["name"]: u["age"] for u in users}
```

## 第七，方法函数定义

Java 需要修饰符、参数类型、返回值类型才能定义方法；Python 用 def 关键字直接定义函数，不用写参数类型，也不用指定返回值。

```java
public static int add(int a, int b) {
    return a + b;
}
```

```python
def add(a, b):
    return a + b
```

## 第八，类和面向对象

Java 用 class 定义类，有构造方法和 this 关键字，一个文件只能有一个公共类，有 public/private 访问修饰符。Python 同样用 class 定义类，init 就是构造方法，self 等同于 Java 里的 this，一个文件可写多个类，无访问修饰符，下划线开头表示约定私有，不用 new 关键字。

```java
class Person {
    private String name;
    public Person(String name) {
        this.name = name;
    }
}
```

```python
class Person:
    def __init__(self, name):
        self.name = name
        self._age = 30  # 约定私有
```

## 第九，数据类 dataclass

它就是 Java 版的 Lombok @Data，加上注解之后，自动生成构造、equals、toString 等方法，不用写一堆模板代码，支持默认值，开发效率大幅提升。

```java
import lombok.Data;
@Data
public class User {
    private String name;
    private int age;
}
```

```python
from dataclasses import dataclass
@dataclass
class User:
    name: str
    age: int
    email: str = ""
```

## 第十，Pydantic

这个是重点，相当于 Java 的参数校验加 JSON 工具的合体。用 BaseModel 定义，自动做字段校验、长度判断、数值范围，还能自定义校验规则，一键转 JSON 字典，LangChain 全套生态都在用，必须掌握。

```java
// Bean Validation + Jackson
public class User {
    @NotBlank
    private String name;
    @Min(0) @Max(150)
    private int age;
}
```

```python
from pydantic import BaseModel, Field
class User(BaseModel):
    name: str = Field(min_length=1)
    age: int = Field(ge=0, le=150)

user = User(name="张三", age=30)
print(user.model_dump_json())
```

## 第十一，装饰器

类似 Java 的注解，但功能更强大，本质是函数包装器。比如写一个计时装饰器，给函数加个 @timer，就能自动统计执行时间，不用改业务代码，非常适合做日志、权限、限流等通用逻辑。

```java
// 注解 + AOP 实现
@Timer
public void slow() {
    try { Thread.sleep(1000); } catch (Exception e) {}
}
```

```python
import time
def timer(func):
    def wrapper():
        s = time.time()
        func()
        print(time.time() - s)
    return wrapper

@timer
def slow():
    time.sleep(1)
```

## 第十二，异步编程

对应 Java 的 CompletableFuture，Python 用 async 和 await，配合 asyncio 实现并发。多个异步任务可以用 gather 一起执行，适合爬虫、接口调用、数据库查询等 IO 密集型场景，代码更简洁直观。

```java
CompletableFuture<Void> future = CompletableFuture.runAsync(() -> {
    // 异步逻辑
});
```

```python
import asyncio
async def fetch(id):
    await asyncio.sleep(1)
    return {"id": id}

async def main():
    res = await asyncio.gather(fetch(1), fetch(2))
```

## 第十三，包管理

Java 用 Maven 或者 Gradle，Python 用 pip 加虚拟环境。创建虚拟环境隔离项目依赖，避免版本冲突，安装依赖只需要一行 pip install，用 requirements.txt 管理，简单轻量。

```xml
<!-- Maven pom.xml -->
<dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-core</artifactId>
</dependency>
```

```python
# requirements.txt
langchain==0.1.0
pydantic==2.0.0

# 安装
pip install -r requirements.txt
```
